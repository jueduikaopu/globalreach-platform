# CRM 客户资产中枢

管理端入口：`/admin/crm.html`。点击“生成三渠道演示数据”会模拟独立站询盘、LinkedIn 私信和海关采购信号；同邮箱/域名自动归入同一客户主档，每条原始询盘与渠道事件仍独立保留。

- 统一主档：客户、来源、标签、企业规模、采购习惯、负责人及销售阶段。
- 时间线：询盘、邮件、社媒、阶段变更、合并、公海回收和认领均记录事件。
- 查重：邮箱、域名精确规则自动归并；公司名称采用 bigram Dice 相似度，得分不低于 0.72 进入人工确认队列。
- 公海：`POST /api/crm/recycle` 默认回收 30 天未跟进的活跃客户；销售可调用 `/claim` 认领。
- 看板：五阶段拖拽更新，漏斗按当前可见客户实时计算。
- 权限：`sales`/`operator` 只能查看自己负责的客户；`crm_manager`、租户管理员和平台管理员可查看团队全部数据与执行合并/回收。

## 生产接入

当前通过统一 `POST /api/crm/ingest` 接入 website、social、customs、email、manual 来源。生产环境应由 Kafka 消费者订阅各模块事件，以外部事件 ID 做幂等键，并将联系方式字段加密存储。演示仓库不包含第三方凭证或真实客户数据。每天低峰由内部调度器调用 `/api/crm/recycle`；数据库结构见 `apps/api/db/migrations/006_crm.sql`。
