# 学生操作手册

## 加入团队与领取账号

注册后使用学校提供的项目/团队信息加入小组。进入实训页选择可用账号，填写用途和预计期限并提交；只有管理员批准后才可使用。不得共享凭证、修改安全设置或把账号用于项目外活动。

## 建站

1. 在模板市场选择完整模板并新建店铺。
2. 在装修器拖拽商品、图片、视频、表单、支付和聊天组件，设置颜色、字体、Logo、页头页脚。
3. 切换桌面/移动预览和 8 种语言，检查阿拉伯语 RTL。
4. 保存草稿后发布；逐一打开静态站和 sitemap，确认产品、联系方式与 SEO 信息。

## 商机和营销

用关键词、6 位 HS 编码或公司名检索；查看企业画像后再收藏，禁止把商业数据对外传播。导出只用于课程项目。邮件营销先选合规模板与收件人，检查退订链接，Mock 环境只记录发送；生产发送必须经过导师批准。社媒发帖选择团队获批账号，检查翻译、素材版权、发布时间和平台状态。

## CRM 与工单

询盘进入 CRM 后先查重，补充公司规模、采购习惯和标签；按时建立跟进待办并拖动销售阶段。长期不跟进会进入公海。工单认领前阅读验收标准和截止时间；提交成果应包含可访问链接、数据来源与结果说明。导师验收通过后只生成“学期末待结算”奖金记录，实际发放以学校现场清单为准。
