# 本地性能测试报告

测试时间：2026-11-02（Asia/Shanghai）  
环境：macOS 本机、Node.js v22.22.2、单进程、JSON 本地存储、回环网络；未经过 CDN、WAF、容器或生产数据库。

## 流量口径

- 60 万 PV/日平均：6.94 PV/s。
- 假设日流量 20% 集中于峰值小时，再乘 4 倍突发：`600000 × 20% ÷ 3600 × 4 = 133.3 页面 RPS`。
- 每 PV 假设 3 个动态 API 请求：约 400 API RPS；生产验收档取 500 RPS。

## 已执行结果

命令：`REQUESTS=1000 CONCURRENCY=50 node scripts/load-test.mjs`

| 场景 | 请求数 | 并发 | 吞吐 | P50 | P95 | P99 | 错误 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 预渲染首页 | 1000 | 50 | 7270.2 RPS | 5.2ms | 13.7ms | 19.6ms | 0 |
| 缓存首页 API | 1000 | 50 | 11049.7 RPS | 4.3ms | 6.5ms | 6.9ms | 0 |
| 注册 API | 20 | 1 | 受认证限流保护 | — | 22.3ms | — | 0 |

结论：本机测试中首页 TTFB 路径和注册接口 P95 均低于验收阈值。首屏 LCP 已实现 RUM 埋点，但本次命令行压测不能测量浏览器渲染 LCP，因此不能用 13.7ms TTFB 代替首屏 1.5 秒结论。

登录接口已在端到端功能测试中成功，单次记录约 19ms；更新后的压测脚本已加入 20 次登录 P95 场景，但因本轮本地端口执行授权额度限制，未取得新的登录 P95 样本。不得把单次值写成 P95。待本地端口权限可用后重新执行同一命令即可补齐。
