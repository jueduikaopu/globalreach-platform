# 管理员操作手册

## 学期初始化

1. 进入“创新创业实训”，创建学期项目并设置起止日期。
2. 建立团队、导入学生账号，核对学号与团队归属。
3. 配置四个月课程表、企业专家、课件和签到规则。
4. 审批学生网络环境申请，默认期限约半年；每日处理到期前 7 天提醒。

## 社媒账号池

录入平台、账号标识与开通时间，真实密钥只放密钥管理系统。租户总量最多 40 个，第 41 个会被系统拒绝。团队提交用途与期限后，管理员审核；批准后账号变为“已分配”。到期核查内容交接、撤销团队授权并归还账号池。Facebook/YouTube 的真实创建和合规审核由中标单位与学校线下协商，系统不自动批量注册平台账号。

## 工单与奖金

1. 发布工单：标题、说明、难度、奖励、截止时间、验收标准必须完整。
2. 学生团队认领后状态为“进行中”；提交成果后变为“待验收”。
3. 导师核对成果链接与指标，填写 0–100 分和评语；通过后状态为“已验收”。
4. 系统按奖励金额生成 `pending_semester_settlement` 奖金记录。
5. 学期末复核团队成员、工单、分数与金额，导出 UTF-8 CSV 发放表；现场发放后由财务/管理员登记凭证。不得把“待结算”误标为已发放。

## 日常运营

- CRM：每天检查重复候选、公海客户和待办；销售只能看本人客户，主管看团队全部。
- 商机/营销：监控查询与发信配额、退信投诉、OAuth 健康和失败重试。
- 数据：每周核对团队产值、工单完成率、账号使用率和培训出勤率。
- 故障：先看 `/api/health`、Prometheus 和结构化日志；按生产手册升级与回滚。
