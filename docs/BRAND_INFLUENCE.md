# 品牌影响力建设

入口 `/admin/brand.html` 提供媒体目录、建站内容复用、多渠道分发、品牌资产和声量归因看板。

内容复用采用 `sourceType + sourceId` 唯一关联。产品直接引用建站 `products.id`，品牌故事引用 `shop-story:<shopId>`；品牌内容记录保存引用和必要展示快照，不要求重新上传媒体文件。重复点击同一来源返回已有品牌内容 ID。

内置演示渠道覆盖搜索引擎、B2B 论坛、新闻媒体、顶级媒体/新闻稿网络、产品发布平台和行业博客。发布适配器均为 `mock_publish`；分发任务为每个渠道生成独立状态、外链、曝光、回链和询盘归因记录，部分失败进入重试状态。

生产接入需要分别获得媒体授权、审核发布规则、实现真实 API/稿件交付、回调验签、URL 抓取和第三方分析归因。Mock 曝光不代表真实媒体投放或可验证的第三方流量。
