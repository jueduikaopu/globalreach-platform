# 院校创新创业实训支撑

管理端入口：`/admin/training.html`。演示按钮会建立学期项目、学生团队与成员，完成一次 Facebook 账号申请审批，开通三套约半年网络环境，生成四个月七门培训计划和签到，并发布一项已认领工单。随后可在页面提交成果、导师评分验收，系统自动生成学期末奖金记录并导出 UTF-8 BOM CSV 发放表。

## 关键规则

- 组织结构：学期项目 → 团队 → 学生成员，所有记录按租户隔离。
- 社媒池：Facebook/YouTube 账号必须先申请后审批；`addSocialAccount` 在租户第 41 个账号处返回 `SOCIAL_ACCOUNT_POOL_LIMIT`。
- 网络环境：记录第三方供应商与隔离配置；距到期不超过 7 天且尚未到期时显示提醒。
- 培训：七类课程覆盖四个月线下深度培训，记录企业专家、课件和逐人签到。
- 工单状态：`open → claimed → submitted → accepted/revision`；只有验收通过才生成奖金，奖金状态默认为学期末现场结算。
- 数据看板：已验收工单奖励计入团队产值；完成率、账号使用率和出勤率均由明细实时计算。

生产部署应将真实账号密钥交由密钥管理服务保存，本模块只保存账号标识与分配关系；网络服务由第三方供应商交付，平台只管理申请、配置摘要和期限。
